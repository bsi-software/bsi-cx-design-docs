CX Design Developer Handbook

This Documentation serves as the definitive guide for creating, customizing, and maintaining designs within the BSI CX Master Template ecosystem.

The primary goal of this documentation is to provide a structured, tutorial-based learning path that enables developers to build high-quality Email, Landing Page and Website designs. It transitions from a purely technical reference to a comprehensive manual designed for professional self-onboarding and long-term knowledge retention.

Target Audience

This documentation is specifically designed for:

  • CX Design Developers: Internal and external professionals building new designs from scratch.

  • External Agencies: Partners working on behalf of BSI customers to customize or extend the Standard Library.

  • Technical Project Managers: To understand the capabilities and technical constraints of the CX Design architecture.

Are you in the right place?

  • If you are a Marketer or End User looking for instructions on how to use the BSI CX interface (Stories, Campaigns), please refer to the BSI CX User Manual (Pink Book).

  • If you are a BSI Core Developer looking for internal build processes and product development infrastructure, please refer to the Internal Product Documentation (Confluence).
